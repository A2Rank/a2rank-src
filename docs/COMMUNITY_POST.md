## 1. 게시글

**제목: A2Rank — 아이온2 랭킹 포인트·전투 기록 미터기 (비공식, 패킷을 읽기만 합니다)**

안녕하세요. 랭킹 포인트 변화와 전투 기록을 보여 주는 윈도우용 도구 **A2Rank**를 만들어서 소개드립니다. 엔씨소프트와 관계없는 비공식 프로그램이고, 무료입니다.

### 이런 걸 보여 줍니다
- 이번 시간의 랭킹 포인트 변화, 오늘 누적, 내 랭킹 (게임의 랭킹 초기화 시각 기준으로 한 시간씩 집계)
- 처치·사망 명단 (상대 이름은 내 PC에만 저장됩니다. 기본은 계속 보관이고, 설정에서 7일·30일 뒤 자동 삭제로 바꿀 수 있습니다)
- 처치별 피해 통계 (스킬별 피해, 치명타·강타·완벽 등, 받은 회복)
- 필드보스 알림 (감시자 카이라는 매일 1·9·13·21시, 정령왕 아그로는 매일 9·21시에 10분·5분·1분 전 알림과 소리)
- 조준 알림 (고른 직업의 상대를 조준하면 짧은 알림음. 기본은 꺼져 있고, 화면으로 오는 정보만 읽습니다)
- 구간별 기록 그래프

### 안전하게 쓰실 수 있는지 — 이렇게 동작합니다
- **게임 파일과 메모리를 건드리지 않습니다.** 게임 프로세스에 접근하지 않고, 게임 화면을 고치거나 끼어들지 않습니다.
- **키보드·마우스를 대신 누르지 않습니다.** 자동 사냥이나 매크로 기능이 없습니다. (단축키는 내가 정한 조합 키를 받는 것뿐입니다.)
- **게임 서버와 주고받는 네트워크 패킷을 내 PC에서 읽기만 합니다.** 와이어샤크 같은 패킷 분석 도구와 같은 방식이고, 패킷 캡처는 Npcap(npcap.com)을 씁니다.
- **인터넷으로 나가는 곳:** 새 버전 확인용 `github.com`(공개 저장소 `A2Rank/releases`)이 전부입니다. 아래 두 가지는 **내가 동의하거나 직접 눌렀을 때만** 서버로 갑니다.
  - 구간 기록 보내기 (캐릭터 이름·서버, 포인트 변화. 상대 이름은 보내지 않음)
  - 데이터 보내기 / 문의하기
- 아무것도 보내지 않아도 모든 기능을 쓸 수 있습니다. 비밀번호·결제 정보는 이 게임의 패킷에 들어 있지 않고, 프로그램은 읽지도 보내지도 않습니다.
- 업데이트는 개발자 키로 서명한 목록만 설치합니다. 설정에서 자동 업데이트를 끌 수 있습니다.

- 게임이 업데이트되면 표시가 틀리거나 안 될 수 있습니다. 참고용 수치로 봐 주세요.

## 2. 커뮤니티 운영자에게 보낼 글

안녕하세요. 아이온2 랭킹 포인트와 전투 기록을 보여 주는 도구 **A2Rank**를 만든 사람입니다. 이 커뮤니티에 소개 글을 올려도 될지 허락을 구하고 싶어서 연락드렸습니다.

혹시 악성코드가 걱정되실까 봐 아래에 정리했습니다.
- 게임 파일·메모리·프로세스를 건드리지 않고, 키 입력을 대신하거나 매크로를 돌리지도 않습니다. 게임 서버와 주고받는 네트워크 패킷을 **내 PC에서 읽기만** 합니다 (Npcap 사용).
- 인터넷 연결은 업데이트 확인용 GitHub 한 곳이 전부이고, 서버로 보내는 기능은 사용자가 동의하거나 직접 누를 때만 동작합니다. 개인정보 처리방침과 이용 안내를 공개해 두었습니다 (https://github.com/A2Rank/releases).
- VirusTotal 검사 결과: https://www.virustotal.com/gui/file/1d1aee438ff4708d273ca2f9f17d311b607ff3cc9dbef9596239b7432423b220 / 설치 파일 SHA-256: `1d1aee438ff4708d273ca2f9f17d311b607ff3cc9dbef9596239b7432423b220`
- 믿기 어려우시면 **Windows 샌드박스나 가상머신에서 먼저 돌려 보셔도 됩니다.** 접속하는 곳과 쓰는 폴더를 직접 확인하실 수 있게 목록을 드리겠습니다.
- 소스 코드를 공개해 두었고 (https://github.com/A2Rank/a2rank-src), 난독화는 하지 않았습니다. 코드 서명 인증서는 아직 없습니다 (설치 때 SmartScreen 안내가 뜹니다). 이 점은 솔직히 말씀드립니다.
